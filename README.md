# Abigail's Collection

### A Feminine Fashion Brand in Addis Ababa, Ethiopia

## About the Brand

Abigail's Collection is a feminine fashion brand based in Addis Ababa, Ethiopia, dedicated to creating unique and elegant dresses for women.

The brand celebrates femininity, individuality, and personal style through distinctive dress designs. Its vision is to offer women fashion pieces that allow them to express their personalities and feel confident in what they wear.

This website introduces Abigail's Collection, showcases its fashion identity, and provides visitors with an opportunity to explore its collections and get in touch with the brand.

## Project Overview

This project is a multi-page website developed as part of the **Web Programming I (COSC 3881), Chapter 2 – Assignment 1: Your First Website** at the American College of Technology.

The website is built using HTML5 only, demonstrating the fundamental concepts of web development covered in Chapter 2.

## Website Pages

The website consists of the following pages:

- **Home:** Introduces Abigail's Collection and its brand identity.
- **About:** Shares the brand's story, vision, and approach to fashion.
- **Collections:** Showcases the unique dresses and designs offered by the brand.
- **Contact:** Allows visitors to reach out to Abigail's Collection through a contact form and email link.

## Technologies Used

- HTML5 – Used to structure the website and organize its content.
- Git – Used for version control and tracking development progress.
- GitHub – Used to host the project and manage its commit history.

## HTML Concepts Demonstrated

This project demonstrates the use of:

- Semantic HTML elements (`header`, `nav`, `main`, and `footer`).
- Headings and paragraphs.
- Images and alternative text.
- Ordered and unordered lists.
- HTML tables.
- Forms, labels, and input fields.
- Internal navigation and external links.
- Email links using `mailto:`.
